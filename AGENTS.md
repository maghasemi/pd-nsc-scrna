# Project Working Agreement

- Use English for every repository file, code identifier, comment, figure label, and report.
- Keep detailed instruction in the project conversation. Explain consequential decisions before dependent analysis and explain unfamiliar code and Git operations there.
- Progress in reviewable milestones. Version 1 covers statistical single-cell analysis.
- Preserve raw inputs. Record provenance and checksums. Audit preprocessing history before applying filters or corrections.
- Treat donors as biological replicates. Document primary contrasts, covariates, and multiple-testing families before inference.
- Keep comments concise and focused on intent. Prefer descriptive names and direct code.
- Record analytical decisions in docs/decisions.md. Update docs/project_charter.md and regenerate docs/project_report.docx when scope or methods change.
- Inspect rendered report pages before delivering a revised Word report.
- Store generated analysis figures in results/figures and curated README graphics in assets/readme.
- Keep reference PDFs and supplementary material locally under references. Track their source URLs, bibliographic details, and checksums.
- Explain each Git milestone in the conversation and use descriptive English commit messages.
